# Financial Analysis & Fraud Prediction

A end-to-end data science project analyzing financial transactions, performing exploratory data analysis (EDA), and modeling fraud detection algorithms.

---

## 📌 Project Overview
Briefly describe the objective of this project in 2–3 sentences.
- **Data Cleaning & Merging**: Processing raw transaction data.
- **Exploratory Data Analysis (EDA)**: Identifying spending trends and anomaly distributions.
- **Financial Analysis**: Deep dive into merchant categories and user behaviors.
- **Fraud Prediction**: Building machine learning models to identify fraudulent transactions.
